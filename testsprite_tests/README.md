# TestSprite Tests - SKV POS Frontend

Generated by the TestSprite workflow (bootstrap → code summary → PRD → test plan → executable tests).

## Prerequisites

- **App running:** Frontend at `http://localhost:5173`, backend at `http://localhost:8000`
- **Python 3.8+** with pip
- **Playwright** browsers installed

## Setup

```bash
# From this directory (skv-pos-fe/testsprite_tests)
pip install -r requirements.txt
playwright install chromium
```

## Run tests

Run all tests (one by one):

```bash
python TC001_Login_success_with_valid_test_credentials.py
python TC002_Redirect_unauthenticated_user_from_protected_routes.py
python TC003_POS_page_loads_and_product_grid_visible.py
```

Or run with pytest if you add a `pytest.ini` and collect `TC*.py`:

```bash
pytest *_*.py -v
```

## Artifacts

| File | Description |
|------|-------------|
| `tmp/config.json` | Bootstrap config (port, project path, credentials) |
| `tmp/code_summary.json` | Codebase analysis and features |
| `standard_prd.json` | Normalized product requirements |
| `testsprite_frontend_test_plan.json` | Full test plan (TC001–TC008) |
| `TC001_*.py` … `TC003_*.py` | Sample Playwright tests (extend to TC008 as needed) |

## Extending

Add more `TC00N_*.py` files following the same pattern (async Playwright, same base_url and login helper). Map each to the test plan IDs in `testsprite_frontend_test_plan.json`.
